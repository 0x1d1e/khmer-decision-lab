# Research Rules

- Prefer simple, reproducible implementations.
- Every experiment must state its hypothesis.
- Fix and record dataset splits, seeds, and model revisions.
- Never train on the test split.
- Use validation data for model selection and calibration.
- Record hardware, configuration, metrics, and failures.
- Compare results against unchanged baselines.
- Never report calibration-slice accuracy as test accuracy.
- Do not fabricate benchmark results.
- Keep large artifacts out of Git.
- Avoid unnecessary abstractions and infrastructure.
